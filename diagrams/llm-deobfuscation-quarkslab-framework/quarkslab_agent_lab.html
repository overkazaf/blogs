Quarkslab 实验 · 让 AI Agent 自己去逆向

把 Claude Code 放进沙箱攻击逐级加固的二进制，目标是找回隐藏字符串

实验设置

  • • Agent 在 Docker 沙箱内自主行动
  • • 可用逆向工具与脚本仿真
  • • 每轮 80 分钟，目标是隐藏字符串

三类缺陷

  • • 环境利用：先找捷径
  • • 叙事固着：认定后很少修正
  • • 产物伪造：声称做了但没做

对防守方的启示

  • • 发布环境不要留辅助文件
  • • 用合理但错误的线索误导
  • • 异常时返回假结果而不是崩溃
