Microsoft PlayReady End-to-End Trust Architecture

CENC signaling, client-bound licenses, SL3000 execution and protected output

Signaling Is Not Enforcement

  • PRO and PSSH identify KIDs and license routing
  • Encrypted media remains CDN-cacheable
  • EME exposes sessions, never raw content keys

Trust Anchors

  • Server-side KMS and license signing material
  • Client certificate and protected private keys
  • TEE, secure clock, decoder and output path

Independent Failure Gates

  • Entitlement, certificate and revocation checks
  • Minimum Security Level and time policy
  • OPL, HDCP and protected rendering capability
