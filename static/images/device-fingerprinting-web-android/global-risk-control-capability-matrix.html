Global Device Risk Control Capability Matrix

基于公开接入文档的能力覆盖比较；不是准确率排名，也不代表所有套餐、地区和客户配置

设备身份型

  • 优势是跨会话归并、环境风险和低接入成本
  • 短板是不了解客户订单、内容和资金结果
  • 应把 visitor/device ID 作为画像节点而非授权凭据

边缘与挑战型

  • 优势是网络视角、全站流量和即时挑战能力
  • 短板是业务语义有限，API 与原生 App 还需单独设计
  • 最适合压低自动化规模，不负责证明自然人身份

业务网络型

  • 优势是事件、损失反馈和跨客户风险模式
  • 短板是垂直领域强、迁移到其他业务未必成立
  • 效果上限取决于客户回传质量与处置闭环
